# fix-persian-farsi-keyboard-layout-on-linux
این فایل دو مشکل رو حل میکنه
- یک : مشکل shift+alt که در نسخه اولیه ، shift به عنوان level 3 در نظر گرفته شده بود که اون خط بخصوص پاک شد
- دو : جایگذاری پ بود که با نوع درستی که در ویندوز استفاده میکردم مطابقتش دادم

# روش به کارگیری فایل ها در همه ی توزیع ها

فایل ir ، فایل لایه فارسی شماست که persain windows توش هست <br>
شما باید اون فایل رو با ir موجود در پوشه ی لایه های کیبرد توزیع خودتون جایگزین کنید <br>
معمولا محل فایل های لایه زبانِ توزیع های لینوکسی در ادرس زیر قرار گرفته ( مخصوصا توزیع مینت و اومارچی که اواخر استفاده کردم) <br>
```
/usr/share/X11/xkb/symbols
```
*** درصورتی که توضیع شما از چیزی غیر از XKB (X Keyboard Extension) استفاده میکنه مسیر متفاوت میشه. <br>


حالا وقت اضاف کردن persain windows به یکی از گزینه های انتخاب زبان هست . این مورد در توزیع های مختلف متفاوت میشه ، میتونه به اسونی توزیع مینت از ابزار های گرافیکی زیر به ترتیب استفاده بشه .
```
keyboard / layout / add / Persain / Persain (windows)
```
و بعدش از alt+shift برای تعویض استفاده کنید

و یا مثل توزیع اومارچی نیاز باشه یه فایل مثل input.lua ویرایش کنید که البته در این مورد نیازی نیست چون فایل رو گذاشتم صرفا جایگذینش کنید با فایل موجود در 
```
/home/hamed/.config/hypr
```
